# Changelog

## 1.3.0 — 2026-10-02

Default production URLs and documentation links now use synterai.com. The artifact API uses api.synterai.com where applicable, and hosted MCP uses https://mcp.synterai.com/mcp.

Existing `SYNTER_API_URL` and `SYNTER_ARTIFACT_API_URL` overrides keep their behavior.

The syntermedia.ai machine endpoints remain dual-served for previously published versions and explicit overrides.
